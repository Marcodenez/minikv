# MiniKV

MiniKV is a program that stays running, keeps data in memory, and lets other programs store and fetch it over the network with commands such as `SET name Ana` and `GET name`. It's a key-value database server written in C.

It is inspired by Redis, but it's my own independent and much smaller program. And was created to help me study C fundamental knowledge with hands on practice and experience.

This project is part of my journey to learn C language.
